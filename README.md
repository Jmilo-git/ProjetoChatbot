TropicalTech

Chatbot de agendamento de viagens com integração de IA.

**Tecnologias**
  - HTML
  - CSS
  - JavaScript
  - Groq API
  - EmailJS

**Funcionalidades**
  - Busca de hotéis  
  - Fluxo de reserva
  - Envio de confirmação por email

**Configuração para executar o chatbot**

  Ao longo do código principal "ChatBot1" estão comentados algumas dicas, 
  como os lugares onde devem ser inseridos as chaves para o uso da IA e também do envio do email.

Groq
  Para criar uma API KEY:
  https://console.groq.com/keys
EmailJS
  Configure:
  https://www.emailjs.com/

**NOTA**

  Vale lembrar que caso não seja configurado, o chatbot irá funcionar parcialmente, as opções de
  busca inteligente de hotéis, integração com IA e envio de email, as demais funções podem ser respondidas pelo JS, 
  mas deve-se colocar as respectivas chaves.
  
  Outros serviços também podem ser utilizados, porém os recomendados apresentaram melhor desempenho além de serem gratuitos.
